<objective>
Make NexTwist's headless `steam` engine Starfield-aware: allow-list AppID 1716740 so
the existing Bethesda add-game/detection flow accepts it verbatim (SFDET-01), add the
new CE2 `Documents/My Games/Starfield` resolver with first-launch typed state and
Wine case-folding/redirection handling (SFDET-02), and add the installed-build read +
advisory version-drift compare (SFDET-03). Testkit fixtures land first (Wave 0) so the
resolver tests have the prefixes they assert against.

Purpose: Phase 6 gates Phases 7 (load order) and 8 (reversible INI). Both need a
resolved CE2 path and a game that is fully allow-listed; this plan produces both, in the
headless engine, with zero writes to the game/prefix.
Output: `crates/steam/src/ce2.rs` (new module), Starfield allow-list arms + `buildid`
seam in `resolve.rs`, and a `My Games` testkit fixture variant.
